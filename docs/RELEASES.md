# Релизы

Все сборки лежат в [Releases](../../releases).
Свежая — помечена `Latest`, её и нужно ставить.

## Как выбрать APK

| Файл | Кому |
|---|---|
| `app-universal-maxTest.apk` | всем, если не знаете свою архитектуру |
| `app-arm64-v8a-maxTest.apk` | современные телефоны (почти все) |
| `app-armeabi-v7a-maxTest.apk` | старые 32-битные устройства |
| `app-x86_64-maxTest.apk` | эмуляторы и x86-планшеты |

## Обновления

Начиная со сборки 39 все APK подписаны одним ключом
(`signing/mrtt-beta.p12`), поэтому новая версия ставится поверх старой:
профили, настройки и привязки сохраняются.

Сборки до 39-й подписаны случайным ключом, который создавался при каждой
сборке. При переходе на актуальную версию старую нужно один раз удалить.

Номер сборки (`versionCode`) растёт с каждым запуском CI, поэтому Android
не считает обновление «той же версией».
